# CBO体験ラボ(CBO育成講座 18期 DAY1)

東京ブランディング大学校「CBO育成講座」DAY1を、上から下へ進みながら体験・記入できる1ページのサイトです。

- 10の段階(ドライブイン → はじめる → 入る → 掘る → シェアする → 自己紹介する → 知る → 個人が法人化する → ドライブアウト → 宿題)
- 各段階は「イメージ / 記入シート / 保存」のタブで、講座のワークシートを見ながら書き込めます
- 段階ごとの入力率と、全体の提出率を表示
- 「提出」で1枚のまとめシートを作成し、「PDFで保存」で書き出せます
- 書いた内容は、閲覧しているブラウザの中(localStorage)にだけ保存されます

## ファイル

- `index.html` … サイト本体
- `img/` … 講座スライド・ワークシートの画像
- `js/` … PDF書き出し用ライブラリ(html2canvas 1.4.1 / jsPDF 2.5.1)
